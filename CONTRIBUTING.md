# Contributing

Nara is a personal, source-available project. It is not maintained as a
community open-source project.

Unsolicited pull requests are not accepted by default. Please do not submit
source code, assets, documentation, or other copyrightable material unless the
repository owner has explicitly invited the contribution.

Before any third-party contribution is merged, the repository owner may
require a separate written copyright assignment, contributor agreement, or
other license grant. A GitHub submission alone must not be interpreted as
transferring ownership of Nara or granting permission to use Nara outside the
terms in LICENSE.

Bug reports and technical discussion may be useful, but they do not grant any
license to the Nara codebase.

See LICENSE for the repository's source-availability and ownership terms.
